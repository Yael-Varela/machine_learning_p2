`compare_models.py` compara el rendimiento de los 6 modelos. Con base en estos resultados, se eligieron **Random Forest** y **SVM** para `tune.py`, que busca sus mejores hiperparámetros, estos dos archivos son los principales que se deben ejecutar para observar el funcionamiento reportado en nuestro archivo PDF. Adicionalmente, para observación, la carpeta `plots` contiene las gráficas de los resultados de esta búsqueda de los mejores hiperparámetros.
